1. Colour clicker:
This is a program that identifies an input colour and provides a corresponding input (currently spacebar)
under the condition of a colour in a specific visual quadrant

Use: uncomment the top to determine coordinate after hovering over it for a few seconds
Set to x,y coords
Set input and delay.

Other adjustments: could be adjusted to a left click under certain conditions
